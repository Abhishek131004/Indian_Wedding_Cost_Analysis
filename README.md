#  Indian Wedding Cost Analysis

A comprehensive Exploratory Data Analysis (EDA) project that analyzes various factors affecting the cost of Indian weddings. This project uncovers spending patterns, identifies major cost drivers, and provides business insights through data visualization and statistical analysis.

---

##  Project Overview

Indian weddings involve numerous expenses such as venue, catering, decoration, photography, accommodation, entertainment, and more. This project analyzes a wedding dataset to understand:

- Cost distribution across different wedding categories
- Impact of guest count on total expenditure
- Popular wedding types and venues
- Spending trends across cities and regions
- Relationships between different cost components
- Key factors influencing overall wedding costs

The objective is to transform raw data into meaningful insights using Python-based data analysis techniques.

---

##  Objectives

- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Identify major contributors to wedding expenses
- Visualize trends using various charts
- Generate business insights for wedding planning and budgeting

##  Key Insights

- Wedding venue and catering account for a significant portion of the total budget.
- Guest count has a strong impact on overall wedding expenses.
- Different wedding types exhibit distinct spending patterns.
- Premium venues and destination weddings generally incur higher costs.
- Cost distribution varies across cities and regions.
